# AstraX Flutter Starter

This folder contains the starter Flutter app scaffold for AstraX. It includes a minimal working app with routes and placeholders for major screens.

Run (locally):
- Install Flutter SDK: https://flutter.dev/docs/get-started/install
- cd flutter
- flutter pub get
- flutter run

Notes:
- Firebase config files are not included. Placeholders are present in /flutter/android and /flutter/ios README steps.
- Replace package id com.astrax.app in AndroidManifest & bundle id in Xcode when ready.
